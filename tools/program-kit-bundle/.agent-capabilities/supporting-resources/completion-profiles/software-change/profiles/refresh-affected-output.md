This is an inert supporting completion profile. It is not a capability,
command, trigger, approval, or independently invokable procedure.

Identify every derived artifact affected by the admitted source change. Use
only its existing backed refresh or generation operation and authoritative
inputs. Do not reproduce generator mechanics, adopt hand-edited generated
bytes, or silently erase drift.

preserve byte-identical output without touching it, and require explicit repair
