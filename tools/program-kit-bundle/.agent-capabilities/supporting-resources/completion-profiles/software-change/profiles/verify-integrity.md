# Verify integrity

This is an inert supporting completion profile. It is not a capability,
command, trigger, approval, or independently invokable procedure.

Run each affected artifact's backed integrity verification after refresh and
again at the publication boundary when publication is separately authorized.
Treat missing, unexpected, or changed generated bytes as tampering with
generated output.

Do not bypass, weaken, delete, or hand-rewrite integrity locks or compile-time
attestations. Stop with exact paths and diagnostics when integrity cannot be
restored through the approved repair flow.
