# Review source

This is an inert supporting completion profile. It is not a capability,
command, trigger, approval, or independently invokable procedure.

Establish the current human request, approved authority, repository guidance,
active work-unit boundary, and current source truth before mutation. Review
existing changes and ownership so unrelated work remains untouched. Stop when
the requested change is materially architectural, approval is absent, or the
selected flow cannot safely own the affected files.

Record the admitted intent, exact inputs, assumptions, exclusions, and any
required escalation before continuing.
