# Publish with separate authority

This is an inert supporting completion profile. It is not a capability,
command, trigger, approval, or independently invokable procedure.

Publication is optional and requires its own explicit human authority. Never
infer publication authority from design, implementation, maintenance, build,
test, commit, or push authority.

When separately authorized, use only the selected backed publication
operation, verify current generated-output integrity at its boundary, and
record the exact destination and evidence. Otherwise record publication as
deliberately not performed.
