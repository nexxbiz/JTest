# Record evidence and review the diff

This is an inert supporting completion profile. It is not a capability,
command, trigger, approval, or independently invokable procedure.

Bind completion evidence to the exact admitted intent, source and derived
artifact bytes, Program Kit version, selected profiles, verification outcomes,
and deliberately omitted actions. Exclude secrets and ephemeral runtime data.

Review the complete diff for scope, generated noise, stale digests, version
changes, unrelated files, hidden authority expansion, and architectural
deviation. Stop when the resulting change is not one coherent reviewable unit.
